# Counter App

This is a simple React-based Counter application.

## Features

- Increment and decrement counter values
- Celebratory Animation every 10 counts
- User-friendly interface
- Responsive design

## Live Demo

Check out the live deployed version of this app here:

[https://rafainamdar04.github.io/counterApp/](https://rafainamdar04.github.io/counterApp/)

## Installation

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/rafainamdar04/counterApp.git

2. Navigate to the project directory:
bash
cd counterApp

3. Install dependencies:
bash
npm install

4. Start the development server:
bash
npm start
The app will be available at http://localhost:3000/.

5. Build & Deploy
To create a production build and deploy to GitHub Pages, use:
bash
npm run build
npm run deploy
